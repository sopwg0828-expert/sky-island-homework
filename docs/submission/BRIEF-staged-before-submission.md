# 我的空中之島

## 我想做什麼

我想做一個可以探索、收集材料和搭橋的立體方塊遊戲。玩家從一座空中浮島出發，採集島上的材料，搭出一條橋，走到另一座浮島。

## 島嶼與畫面

- 島嶼表面是草地，中間有一座小山。
- 河流從山上往下流，成為島上的主要景色。
- 浮島底下露出石頭，能看出島嶼懸浮在空中的樣子。
- 天空是藍天白雲，並且看得到太陽。
- 地形與物品採用像積木一樣的立體方塊風格。
- 除了出發的島，還有另一座需要搭橋才能抵達的浮島。

## 玩家可以做什麼

- 在島上移動，探索草地、小山和河流。
- 按住滑鼠左鍵挖方塊，看到裂痕逐漸增加，直到方塊被挖掉。
- 泥土較快挖完，石頭需要較長的時間。
- 挖到一半放開左鍵時，裂痕消失，下次需要重新挖。
- 挖掉方塊後，掉出同種類的小方塊。
- 走近掉落物後，將它撿進背包，對應材料的數量增加。
- 選擇背包中的材料，按滑鼠右鍵放置方塊，並消耗一個材料。
- 用收集到的方塊逐步搭橋，走到另一座浮島。

## 遊戲目標

收集足夠的材料，搭出一條能讓玩家通行的橋，並成功走到另一座浮島。

例如：先在出發的島採集泥土與石頭，再把材料放在兩座島之間，逐格延伸成橋，最後沿著橋走到對岸。

## 這次先完成的內容

- 草地浮島、小山、河流，以及底部露出的石頭。
- 藍天、白雲、太陽與立體方塊畫面。
- 玩家移動，以及挖掘、掉落、拾取、背包計數和放置方塊的完整流程。
- 另一座浮島，以及利用材料搭橋抵達的玩法。
- 完成 VERIFY.md 第 1 批老師指定的測試。

## 還要決定的細節

- 河流是否只沿固定水道流動，或會隨挖掘與放置方塊而改道。
- 玩家掉下浮島後要怎麼重新開始。
- 到達另一座浮島後，要用什麼畫面或提示表示完成。
- 是否加入其他趣味操作；目前尚未選定，不列入已確定的功能。
