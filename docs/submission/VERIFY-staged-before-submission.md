## 第 1 批：老師想的測試（照抄，不用改）

### STEP 1 挖方塊

- [ ] 按住左鍵挖 → 越裂越大，不到 1 秒不見
- [ ] 不可以 只點一下就不見
- [ ] 挖到一半放開 → 裂痕不見，要從頭挖
- [ ] 挖石頭 → 比泥土久，大約 2 秒

### STEP 2 掉出來

- [ ] 方塊不見 → 彈出同種類的小方塊，慢慢轉
- [ ] 不可以 浮在空中、穿過地面

### STEP 3 撿起來

- [ ] 走到旁邊 → 飛到身上，那一格數字 +1
- [ ] 不可以 站在 3 格外也被撿起來

### STEP 4 放回去

- [ ] 選那一格按右鍵 → 放出一格，數字 −1
- [ ] 不可以 數字是 0 還放得出來
- [ ] 整串走一遍 → 數字回到原本

## 第 2 批：我自己想的測試

### STEP 5 探索草地浮島與河流

- [ ] 進入遊戲並環顧四周 → 看得到藍天、白雲、太陽，以及兩座分開的立體方塊浮島
- [ ] 在出發島上走動並觀察小山 → 看得到草地、島中央的小山，以及浮島側面下方露出的石頭
- [ ] 沿著河流從山上走到下游 → 看得到河流由高處往低處延伸，水面有持續朝下游移動的效果
- [ ] 不可以 兩座島一開始就有地面連在一起，讓玩家不用搭橋就能直接走到對岸

### STEP 6 收集材料，搭橋到另一座島

- [ ] 挖下並撿起 5 個泥土方塊 → 背包泥土數量比採集前增加 5
- [ ] 選擇泥土，從島邊朝另一座島連續放置 5 格 → 看得到相連的 5 格橋面，背包泥土數量減少 5
- [ ] 走到剛搭好的橋面上並停留 3 秒 → 玩家能站在橋上，不會穿過橋面掉下去
- [ ] 繼續收集材料並把橋接到另一座島 → 玩家能沿橋走到另一座島，並站在對岸草地上
- [ ] 不可以 玩家站在連續且沒有缺口的橋面中央時，穿過方塊掉下去
