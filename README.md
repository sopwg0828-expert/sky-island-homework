# 空中之島

作業文件、協作來源及 Git 歷史限制請見 [SUBMISSION.md](SUBMISSION.md)。

目前完成 STEP 0～4 的本機試玩版：兩座分開的草地浮島、小山、動態河流、露出的石頭及底層基岩、藍天白雲與太陽；可以走路、轉動視角、挖掘方塊、看見掉落物、靠近收進材料背包，再選材料右鍵放回。掉到島底以下會恢復初始地形並回到起點，背包與掉落物也會清空。

可以跳躍，踩進河流會沿下游被沖出島外再重新開始。河水有立體厚度與瀑布，挖開河岸會流入空洞，放方塊可擋水。石頭已依最新要求改回 2 秒，兩島底層基岩無法挖掘。搭橋到對岸的完整人工驗收與學校舊電腦效能仍待驗證。

## 開啟方式

1. 在此資料夾雙擊 `啟動網站.cmd`，保留啟動後的視窗。
2. 用瀏覽器開啟 <http://127.0.0.1:4173>。
3. 按「走進小島」。

也可在已安裝 Node.js 的電腦，於此資料夾執行 `node serve.mjs`。這只是本機預覽靜態檔案的工具；上傳靜態網站空間後不需要執行它。若顯示連接埠已使用，先開上面的網址確認是否已有本專案運作。

不要直接雙擊 index.html，瀏覽器可能限制本機檔案載入 JavaScript 模組。

## 操作

- W、A、S、D：前、左、後、右移動。
- 移動滑鼠直接轉動視角，準心固定中央；用中央準心對準附近方塊，按住左鍵挖掘：草地與泥土 0.8 秒、石頭 2 秒。放開或換目標會重新計時。
- 進入遊戲會嘗試鎖定滑鼠；若瀏覽器不支援，仍可在場景內直接移動滑鼠轉向。Esc 暫停並釋放滑鼠。方向鍵也能轉向及抬頭低頭。
- 按 1／2／3 或點背包選草地／泥土／石頭，再對著方塊表面點一下右鍵，在相鄰空格放出一塊並扣 1；沒有材料、空間被占用、碰到玩家或超出世界邊界時不放置也不扣數量。
- 島間搭橋：先走到島邊，往前下方的空隙看，將游標移到要接出的下一格；看到綠色方塊預覽時按右鍵，接著走上新橋面，再放下一格。不能在沒有相鄰支撐的遠方空中直接生成方塊。
- 挖碎後出現旋轉的小方塊，走到約一格內會飛向身上並進入材料背包。草地、泥土、石頭分開計數。
- 空白鍵跳躍，畫面跟著升降；空中不能再次起跳，按住不會連跳。遇到一格高的地形也可自動踏上。
- 小心河流：腳踩進去後會沿下游被沖出島外，落入虛空後整局重新開始。
- Esc 或「暫停」：回到總覽，再按「繼續探索」回到原位置。
- 右上角四角圖示：切換全螢幕。
- 觸控裝置：畫面方向按鈕移動，拖曳場景轉動視角，按「跳躍」起跳，按住「按住挖掘」挖畫面中央的方塊；尚未在實體觸控裝置驗證。
- 掉到島底以下：自動從頭開始，材料背包歸零，清除掉落物及挖掘進度，恢復初始地形。橋面的重設將在放置功能完成後驗證。

## 測試

執行 `node --test tests/*.test.mjs`，目前 59 項自動測試通過。測試使用 Node.js 內建功能，不需要安裝額外套件；本機使用 Node.js v24.19.0 驗證。

- `docs/step0-red.txt`：先寫測試、功能尚未實作時的失敗紀錄。
- `docs/step0-green.txt`：實作後的測試結果。
- `docs/step1-red.txt`、`docs/step2-red.txt`、`docs/step3-red.txt`：各步功能未實作時的失敗紀錄。
- `docs/step3-pit-red.txt`：試玩發現坑旁拾取問題後，先補測試確認失敗的紀錄。
- `docs/collection-green.txt`：完成挖掘、掉落、拾取與坑旁拾取修正後的 29 項測試結果。
- `docs/step4-red.txt`、`docs/step4-green.txt`：放置功能的八項測試，先失敗並提交，再實作至通過。
- `docs/submission/final-tests.txt`：含新版操作、動態立體水、基岩與石頭兩秒設定的 59 項測試結果。
- `docs/water-bedrock-red.txt`、`docs/water-channel-red.txt`、`docs/water-bank-red.txt`：最新需求及河岸防淹水測試先失敗的紀錄；`docs/water-bedrock-green.txt` 為 59 項通過結果。
- `docs/controls-red.txt`、`docs/controls-green.txt`：使用者新規格先失敗再通過的紀錄。
- `docs/bridge-red.txt`、`docs/bridge-green.txt`：島邊向空隙搭橋的失敗及通過紀錄；含實際雙島地形搭六格、走到對岸站穩三秒的自動測試。
- `docs/submission/bridge-preview.jpg`、`bridge-placed.jpg`：瀏覽器實際出現綠色橋面預覽、放出橋面並走上去的畫面。
- `docs/submission/step4-playtest.jpg`：瀏覽器走完挖、撿、放後的實際畫面。
- 自動測試不代表所有視覺、實際操作和學校電腦效能都通過，待驗證項目列在 PLANS.md。
