作業文件、協作來源及 Git 歷史限制請見 [SUBMISSION.md](SUBMISSION.md)。

目前完成 STEP 0～3 的本機試玩版：兩座分開的草地浮島、小山、固定河道、露出的石頭、藍天白雲與太陽；可以走路、轉動視角、挖掘方塊、看見掉落物並靠近收進材料背包。掉到島底以下會恢復初始地形並回到起點，背包與掉落物也會清空。

放置與搭橋尚未製作，依 PLANS.md 繼續進行。河流現在是固定景觀，向下游流動的動畫留到 STEP 5。學校舊電腦效能尚未實測。本次使用者明確授權一次完成 STEP 1～3。

## 開啟方式

1. 在此資料夾雙擊 `啟動網站.cmd`，保留啟動後的視窗。
2. 用瀏覽器開啟 <http://127.0.0.1:4173>。
3. 按「走進小島」。

也可在已安裝 Node.js 的電腦，於此資料夾執行 `node serve.mjs`。這只是本機預覽靜態檔案的工具；上傳靜態網站空間後不需要執行它。若顯示連接埠已使用，先開上面的網址確認是否已有本專案運作。

不要直接雙擊 index.html，瀏覽器可能限制本機檔案載入 JavaScript 模組。

## 操作

- W、A、S、D：前、左、後、右移動。
- 指向附近的方塊並按住滑鼠左鍵：挖掘；草地與泥土 0.8 秒，石頭 2 秒。放開或更換目標會重新計時。
- 按住滑鼠右鍵拖曳：轉動視角。左右方向鍵轉向，上下方向鍵抬頭或低頭。
- 挖碎後出現旋轉的小方塊，走到約一格內會飛向身上並進入材料背包。草地、泥土、石頭分開計數。
- 遇到一格高的地形會自動踏上；沒有跳躍或飛行。
- Esc 或「暫停」：回到總覽，再按「繼續探索」回到原位置。
- 右上角四角圖示：切換全螢幕。
- 觸控裝置：畫面方向按鈕移動，拖曳場景轉動視角，按住「按住挖掘」挖畫面中央的方塊；尚未在實體觸控裝置驗證。
- 掉到島底以下：自動從頭開始，材料背包歸零，清除掉落物及挖掘進度，恢復初始地形。橋面的重設將在放置功能完成後驗證。

## 測試

執行 `node --test tests/*.test.mjs`，目前 29 項自動測試通過。

- `docs/step0-red.txt`：先寫測試、功能尚未實作時的失敗紀錄。
- `docs/step0-green.txt`：實作後的測試結果。
- `docs/step1-red.txt`、`docs/step2-red.txt`、`docs/step3-red.txt`：各步功能未實作時的失敗紀錄。
- `docs/step3-pit-red.txt`：試玩發現坑旁拾取問題後，先補測試確認失敗的紀錄。
- `docs/collection-green.txt`：完成挖掘、掉落、拾取與坑旁拾取修正後的 29 項測試結果。
- 自動測試不代表所有視覺、實際操作和學校電腦效能都通過，待驗證項目列在 PLANS.md。
